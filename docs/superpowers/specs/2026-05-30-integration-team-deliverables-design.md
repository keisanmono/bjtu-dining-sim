# 集成阶段团队交付物设计

## 交付范围

本次生成第 20 组集成阶段团队交付物，放入：

- `deliverables/软件综合实训_20组_集成阶段团队材料/`

交付文件包括：

- `20组_联调测试报告.pdf`
- `20组_集成阶段小组沟通交流记录.pdf`
- `软件综合实训_20组_系统源代码.zip`

压缩包内包含系统源代码和源代码说明文档。由于本机没有 `rar` 工具，且课程命名规范允许 `.rar/zip`，系统源代码包使用 `.zip`。

## 内容要求

### 联调测试报告

报告覆盖课程要求中的两类测试：

1. 接口联调测试：验证前端、FastAPI 接口、仿真核心、推荐解释和 SQLite 存储之间能够正常通信。
2. 系统联调测试：以完整用户任务为用例，验证参数配置、实时仿真、结果分析、推荐解释、导出和校园到达等整体能力。

报告依据仓库现有代码和测试整理，不编造系统不存在的功能。自动化验证包括后端 `unittest` 和前端 `npm test`。

### 集成阶段沟通记录

沟通记录沿用开发阶段沟通记录的表格结构，记录集成阶段围绕联调范围、接口字段、测试环境、交付材料和源码打包进行的多次沟通。

### 系统源代码包

压缩包内创建 `SRC_20组/` 工程目录，包含：

- `backend/`
- `frontend/`
- `tests/`
- `doc/`
- `scripts/`
- `README.md`
- `backend/requirements.txt`
- `frontend/package.json`
- `frontend/package-lock.json`
- `20组_系统源代码说明.md`
- `20组_系统源代码说明.pdf`

压缩包排除运行环境、缓存、依赖和生成数据，包括 `.git/`、`.venv/`、`backend/.venv/`、`frontend/node_modules/`、`data/`、`logs/`、`__pycache__/`、`.pytest_cache/`、临时 LaTeX 日志和已有 deliverables。

## 验收标准

- 三个团队交付文件均存在，命名符合课程要求。
- PDF 文件非空且可识别为 PDF。
- 联调测试报告包含接口联调测试和系统联调测试两部分。
- 沟通记录包含集成阶段多次沟通内容。
- 系统源代码 zip 内含源码说明文档和项目核心源码，不包含大体积依赖目录。
